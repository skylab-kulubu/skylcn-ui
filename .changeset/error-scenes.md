New error pages draw the club's moving scenes, the same set for each kind in every product. Ten kinds, each with two or three drawings and their own words: 404 (GECEKODU at 03:47, a page moved by WEBLAB, a link cut short), 500 (the server on GECEKODU's midnight break, a smoking server), 403 (the SKYDAYS CTF that refuses guessed flags, the team lead's chat, the SKYDAYS key that will not turn), offline (YıldızJam paused with its plug out, your internet cut), an expired session (GECEKODU's upside-down screen, the ARTLAB robot asleep, the USB prank on an unlocked laptop), unavailable for 502/503/504 and timeouts (the server gone for tea, ALGOLAB's time limit), an expired link (410), too many tries (429: the SKYDAYS shield, YıldızPlace's wait), cookies blocked and a closed form. `ErrorScenePage` is the whole page and shows a random drawing on each visit, picked in the browser without a hydration mismatch, hidden while it hydrates and shown after 1.5 seconds if it never does; `variant` fixes one, `pickErrorSceneVariant(kind, seed?)` picks on the server and `status` picks where a kind's drawings answer different causes (unavailable: 504 draws the time limit, 502 and 503 the server gone for tea). From a server page it sends only its kind's drawings as markup; each kind has its own page (NotFoundScenePage … FormClosedScenePage) for a client page to bundle that kind alone. `error-scene.css` holds the scenes' rules alone for an app without the theme, and `error-scenes/` the drawings as SVG files and JSON for a page without React. `ErrorScene kind variant`, one export per kind (NotFoundScene, ServerErrorScene, ForbiddenScene, OfflineScene, SessionExpiredScene, UnavailableScene, LinkExpiredScene, TooManyRequestsScene, CookiesBlockedScene, FormClosedScene) and `errorSceneText(kind, locale, variant)` build a page by hand. One line language in theme colours for light and dark, inline SVG with CSS animation, no inline style, still under reduced motion or `animated={false}`, hidden from screen readers. StatusPage takes `scene`, drawn in place of the large code, which turns into a small line under it; TaskPage takes `top`, a picture above the title.
