Combobox can create what was typed (`onCreate`), search on the server (`onSearch`, `loading`), show a locked value (`readOnly`) and take several picks as removable chips (`multiple`); MultiSelect is now Combobox multiple under its old name. Combobox and NumberField take `size`. The list rises in order as it opens and eases its height as a search narrows it.
